Edge Processing Note

Raw video streams remain cached on the bus's internal storage. Only small telemetry JSON records (coordinates, class, bounding boxes) are transmitted to the municipal center, conserving cellular bandwidth.

Reducing duplicate and low-confidence observations. When independent buses observe the same defect near the same location within the configured demo window, the evidence is grouped and confidence can strengthen.

WHY CURVESENSE?

Public buses repeatedly travel fixed routes. CurveSense reconstructs each pass as a simulated trajectory, compares it with the ideal road-design path, and evaluates apex deviation, speed reduction, and braking behaviour to identify recurring curve-risk patterns.
